# FamiliarBot League itch.io Upload

Upload the prepared zip file to itch.io as an HTML game.

Required itch.io settings:

- Kind of project: `HTML`
- Upload type: `This file will be played in the browser`
- Orientation: landscape
- Suggested viewport: `1280 x 720`
- Enable fullscreen button: yes

The package has `index.html` at the top level, which itch.io needs for browser games.
