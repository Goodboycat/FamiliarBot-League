# Power FBX Assets

These files are upload-ready `.fbx` assets for each Familiar Bot League bot power.

Each file is copied from the bot's original model and renamed for the bot's special power, so Cartwheel or another tool can import the right bot/power pairing quickly.

The power design data lives in:

- `../bots/bot_powers.json`
- `../bots/<bot-id>/power.json`

## Files

- `atlas/atlas_balance_burst.fbx`
- `blaze/blaze_flame_uppercut.fbx`
- `volt/volt_lightning_dash.fbx`
- `sage/sage_repair_field.fbx`
- `bastion/bastion_fortress_guard.fbx`
- `vex/vex_fox_glitch.fbx`
- `bruno/bruno_bear_slam.fbx`
